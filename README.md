# AI-помощник для подготовки товарных описаний

Прототип сервиса для генерации карточек товаров B2B-магазина контрольно-измерительных приборов с использованием LLM.

**Тестовое задание для СОЮЗ-ПРИБОР**
**Автор:** Бахимов Олег Николаевич
**Дата:** 13 ноября 2026 г.

---

## Цель проекта

Сервис принимает данные о контрольно-измерительном приборе и генерирует готовую карточку товара:

- SEO-заголовок (до 70 символов)
- SEO-описание (800–1200 символов)
- Структурированный список характеристик
- 3–5 поисковых запросов
- Commercial-блок для менеджера
- Список отсутствующих данных

**Ключевой принцип:** модель НЕ выдумывает характеристики. Все технические значения берутся только из входных данных.

## Быстрый старт

### Требования
- Python 3.11+
- Аккаунт на [RouterAI](https://routerai.ru)
- ~50 ₽ на балансе

### Установка

```bash
# 1. Клонировать
git clone https://github.com/TomRusski/souz-pribor-ai-assistant.git
cd souz-pribor-ai-assistant

# 2. Виртуальное окружение
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Linux/Mac

# 3. Зависимости
pip install -r requirements.txt

# 4. Конфигурация
cp .env.example .env
# Вставить ROUTERAI_API_KEY

# 5. Запуск
python main.py
